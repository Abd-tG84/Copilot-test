# Copilotを活用したスプリントバックログリファインメントの進め方

- バックログアイテム（ユーザーストーリーや要件）の要約・整理をCopilotで自動化し、リファインメントの議論を効率化
- Copilotに「このIssueの要点・受け入れ基準をまとめてください」と依頼し、議論の土台を素早く作成
- タスク分解や見積もり（Priority/Size/Estimate）のたたき台をCopilotで自動生成し、チームでレビュー・合意形成
- 不明点や追加情報が必要な箇所をCopilotにリストアップさせ、事前に明確化
- gh CLIでバックログアイテムの一覧や詳細を抽出し、Copilotに要約・分解・見積もりを依頼
- リファインメント議事録やアクションアイテムをCopilotで自動生成し、チームに共有
- Copilotの提案は必ず内容を確認し、必要に応じて修正・追記する

---

## 具体的な活用例

1. **バックログアイテムの要約・受け入れ基準の整理**
   - Copilotに「このIssueの要点・受け入れ基準をまとめてください」と依頼
2. **タスク分解・見積もりの自動化**
   - Copilotに「このバックログアイテムをタスクに分解し、Priority/Size/Estimateを付与してください」と依頼
3. **不明点・追加情報の洗い出し**
   - Copilotに「この要件で不明点や追加で確認すべきことをリストアップしてください」と依頼
4. **リファインメント議事録・アクションアイテムの自動生成**
   - Copilotで議事録やアクションリストを自動生成し、共有
