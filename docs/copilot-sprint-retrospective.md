# Copilotを活用したスプリントレトロスペクティブ（振りかえり）の進め方

- スプリント期間中の出来事や課題、良かった点・改善点を自動で要約・整理
- gh CLIでIssueやPRのコメント・議事録・アクションアイテムを抽出し、Copilotに要約依頼
- Copilotに「スプリントの良かった点・課題・次のアクションをまとめてください」と依頼し、ふりかえり用サマリを自動生成
- KPT（Keep/Problem/Try）やYWT（やったこと/わかったこと/次やること）などのテンプレートを自動生成
- チームメンバーの発言やアンケート結果を集約し、Copilotで議事録やアクションリストを作成
- Copilotの提案は必ず内容を確認し、必要に応じて修正・追記する

---

## 具体的な活用例

1. **ふりかえり用データの抽出と要約**
   - gh CLIでスプリント期間中のIssue/PRコメントやアクションアイテムを抽出し、Copilotに要約依頼
2. **KPTやYWTテンプレートの自動生成**
   - Copilotに「この内容でKPT（Keep/Problem/Try）をまとめてください」と依頼
3. **アクションアイテム・議事録の自動作成**
   - Copilotでアクションリストや議事録を自動生成し、共有
