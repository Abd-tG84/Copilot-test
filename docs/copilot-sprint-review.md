# Copilotを活用したスプリントレビューの進め方

- スプリントで完了したIssueやPRの一覧を自動抽出し、成果物リストやデモ対象を整理
- gh CLIで `gh issue list --state closed --milestone "Sprint 1"` などを使い、完了タスクを集計
- Copilotに「このスプリントで完了した作業内容を要約してください」と依頼し、成果サマリやレビュー用資料を自動生成
- デモ用の説明文やQAリストもCopilotで自動生成し、発表準備を効率化
- Copilotの提案は必ず内容を確認し、必要に応じて修正・追記する

---

## 具体的な活用例

1. **完了Issue/PRの抽出と要約**
   - gh CLIでスプリント完了分のIssue/PRを抽出し、Copilotに要約依頼
2. **成果物リスト・デモ資料の自動生成**
   - Copilotに「このリストからデモ対象を抽出し、説明文を作成してください」と依頼
3. **議事録・QAリストの自動作成**
   - Copilotで議事録テンプレートやQAリストを自動生成し、共有
