# Copilot活用ガイド集（スクラム運用向け）

このリポジトリは、GitHub Copilotとgh CLIを活用したスクラム運用（スプリントプランニング・デイリースクラム・スプリントレビュー・レトロスペクティブ）の実践ガイドをまとめたものです。

## 各ドキュメントの概要とリンク

- [copilot-sprint-planning.md](./copilot-sprint-planning.md)
  - スプリントプランニングでのCopilot活用方法・タスク分解・見積もり・Issue/Project運用の自動化ポイントを解説

- [copilot-daily-scrum.md](./copilot-daily-scrum.md)
  - デイリースクラムでの進捗・課題の自動要約、進捗サマリや可視化、議事録自動化の方法を紹介

- [copilot-sprint-review.md](./copilot-sprint-review.md)
  - スプリントレビューでの成果物リスト・デモ資料・議事録・QAリストの自動生成方法を解説

- [copilot-sprint-retrospective.md](./copilot-sprint-retrospective.md)
  - スプリントレトロスペクティブ（振りかえり）でのKPTやアクションアイテム自動整理、ふりかえりサマリ作成の方法を紹介

## 使い方

- 各ドキュメントを参照し、Copilotとgh CLIを活用したスクラム運用の自動化・効率化にご活用ください。
- コマンド例やプロンプト例も掲載しています。
